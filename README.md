# Aulas UMC 2026.2 - Programação Orientada a Objetos em Java

Bem-vindo ao repositório de treinamento em **Java Orientado a Objetos**, desenvolvido para apoiar os estudos desde os conceitos mais básicos até tópicos avançados da linguagem.

## Objetivo

Este repositório foi criado para servir como ambiente de aprendizado, prática e evolução contínua em Programação Orientada a Objetos (POO) utilizando Java 21.

Ao longo da jornada serão explorados temas como:

- Sintaxe básica da linguagem Java
- Classes e Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Abstração
- Coleções
- Tratamento de Exceções
- Generics
- Streams e Expressões Lambda
- Testes Automatizados
- Boas Práticas e Clean Code
- Padrões de Projeto (Design Patterns)

## Para quem está começando

Se você está iniciando sua trajetória em programação, lembre-se de uma coisa importante:

> Ninguém nasce sabendo programar.

Todo desenvolvedor experiente já enfrentou erros de compilação, dúvidas aparentemente simples e momentos de frustração. Essas dificuldades fazem parte do processo de aprendizado.

Cada exercício resolvido, cada erro corrigido e cada conceito compreendido representa um passo importante na sua evolução.

Não tenha medo de errar. O erro é uma das ferramentas mais poderosas para aprender programação.

## Uma mensagem de motivação

Aprender programação é como aprender um novo idioma. No começo tudo parece estranho, mas com prática e persistência você começa a entender, construir e criar coisas cada vez mais complexas.

Mantenha a curiosidade, faça perguntas, pratique constantemente e celebre cada pequena conquista.

O objetivo não é ser perfeito no primeiro dia.

O objetivo é ser melhor hoje do que você era ontem.

Acredite no seu potencial. Com dedicação, disciplina e prática, você será capaz de desenvolver soluções incríveis e construir uma carreira sólida na área de tecnologia.

Bons estudos e seja muito bem-vindo ao mundo da Programação Orientada a Objetos!
